SSH

Encryption and login happen in this tab. The local bridge only relays encrypted bytes; nothing is sent to GitHub.

Server
Login

RSA or ECDSA keys in PKCS#8 format (passphrase-protected is fine). Convert a copy of an existing key with ssh-keygen -p -m PKCS8 -f copy_of_key. Ed25519 keys are not supported.

The server's questions (password, one-time code…) will be asked one by one.

Local bridge
How do I start the bridge?

Browsers can't open SSH connections directly, so a tiny relay runs on your own computer (it only listens on 127.0.0.1). Download bridge.py and run:

python3 bridge.py

It prints a link that fills in the port and token for you. Restrict targets with --allow host:22.

Chrome may ask to allow access to devices on your local network. Safari blocks connections from https pages to localhost; use Chrome or Firefox.
