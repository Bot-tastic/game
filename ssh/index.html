SSH

Encryption and login happen in this tab. The relay only passes encrypted bytes along; nothing is sent to GitHub.

Server

As seen from the relay. If the relay runs on the server itself, keep localhost.

Login

RSA or ECDSA keys in PKCS#8 format (passphrase-protected is fine). Convert a copy of an existing key with ssh-keygen -p -m PKCS8 -f copy_of_key. Ed25519 keys are not supported.

The server's questions (password, one-time code…) will be asked one by one.

Relay
How do I set up the relay?

Browsers (Safari included) can't open SSH connections themselves, so a tiny relay runs on the computer you want to reach. Nothing gets installed on this device. On that computer, download bridge.py and run:

python3 bridge.py --tunnel

That uses a free cloudflared tunnel, so there's no domain or router setup. Have a domain and certificate? Use --tls-cert/--tls-key/--public-url instead.

It prints a link that fills in the relay address and token. Send that link to this device, open it, tick "Remember" below and bookmark the page or add it to the Home Screen.

By default the relay only connects to that computer's own SSH server (localhost:22). Widen it with --allow host:22.
